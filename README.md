# furniture_portfolio_1

> **ATELIER** — Architectural Minimalist Furniture Experience.

An ultra-refined, architectural furniture showcase featuring interactive 3D WebGL presentation, smooth kinetic motion, and responsive editorial layout.

## 🚀 Key Features
- **Cinematic Hero**: PBR rendered furniture with interactive lighting and orbital view
- **Architectural Curation**: Clean editorial typography inspired by Scandinavian architectural design
- **Production HTML & Bundle**: Pre-compiled production build included in `dist/`

## 🛠 Tech Stack
- **React 18** + **Vite**
- **Three.js** / **@react-three/fiber** & **@react-three/drei**
- **GSAP** (GreenSock Animation Platform)
- **Tailwind CSS**

## 💻 Quick Start
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
